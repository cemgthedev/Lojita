# Lojita
Lojita é um marketplace multi-vendedor em que usuários criam lojas, publicam produtos com variantes (SKU, preço, estoque e atributos) e vendem para outros usuários. O projeto inclui carrinho, favoritos, pedidos divididos por loja, cupons de desconto, pagamentos via provedor externo, avaliações de produtos, chat e tickets de suporte.
